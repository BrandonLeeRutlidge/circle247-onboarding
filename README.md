# Circle247 onboarding

A clickable prototype of the Circle247 onboarding flow, built mobile first.

**Live:** https://brandonleerutlidge.github.io/circle247-onboarding/

The screen's shape decides the layout. Taller than wide (close to 9:16: phones, tablets held upright) it fills the screen like the real app. Wider than tall (close to 16:9: desktops, tablets on their side) the same phone sized app sits in a handset frame on the brand background, with a QR code to open it on your phone.

Plain HTML, CSS and JavaScript. No build step: `index.html`, `app.css` and `app.js` are the whole thing.
